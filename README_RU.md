# AI Player Android DevKit v0.2.0

## Честный статус
Это **исходный проект**, а не готовый `.geode`-пакет. Он содержит минимальную основу для сбора данных о максимальной X-позиции и сохранения рекорда через Geode saved values.

В этой версии пока НЕ реализованы:
- автоматическое нажатие/отпускание кнопки;
- определение столкновения и точного места смерти;
- полноценное обучение с выбором действий;
- интерфейс Start AI / Stop AI;
- универсальная поддержка всех режимов и триггеров.

Поэтому этот проект пока не является работающим автономным ботом. Я не могу честно назвать его готовым к установке или гарантировать компиляцию без сборки против точной версии Geode SDK.

## Сборка Android
Официальная инструкция Geode: https://docs.geode-sdk.org/getting-started/create-mod/

Официальная документация указывает, что Android-сборка требует Android NDK, установленных Geode Android binaries и Geode CLI. В терминале настроенного окружения команда обычно имеет вид:

    geode sdk install-binaries -p android64
    geode build -p android64

Для 32-битного окружения используйте android32 вместо android64. Архитектуру необходимо проверить для своей установки.

После успешной сборки установочный `.geode` появится в папке сборки Android. Переносить и устанавливать его следует через поддерживаемый Geode-путь/менеджер модов. Не устанавливайте этот ZIP как мод: это архив исходников.

## План разработки
1. Подтвердить сборку минимального мода для точной версии SDK.
2. Добавить безопасное включение/выключение автопилота и управление вводом через совместимые API Geode.
3. Реализовать обучение сначала только для Cube в обычном режиме.
4. Сохранять проверенные последовательности действий и сравнивать прогресс между попытками.
5. Тестировать отдельно на простых уровнях, затем расширять режимы.

Нельзя гарантировать прохождение абсолютно любого уровня: некоторые уровни используют сложные триггеры, смену гравитации/скорости, порталы, dual и нестандартную геометрию.
